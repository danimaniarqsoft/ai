## Other names
- Logit Regression
## Definition

Is used to estimate the probability that an instance belongs to a particular class (eg. what is the probability that this email is spam?). If the estimated probability is greather than 50% then the model predicts that the instance belongs to that class (called the positive class, labeled "1"), or else it predicts that it does not ( labeled "0"). This makes it a binary classifier.

It uses the [[Sigmoid]] function
